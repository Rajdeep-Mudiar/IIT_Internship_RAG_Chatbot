# AI Model Battle

This document explains the end-to-end implementation of the **AI Model Battle** (parallel benchmarking) feature.

---

## 1. Feature Overview

The AI Model Battle feature allows administrators to query the same benchmark prompt across multiple active local models (e.g., Qwen3, Phi, Gemma, Llama3) and cloud APIs (e.g., Gemini, Groq, DeepSeek) simultaneously. It logs response text, computes latency, measures groundedness against RAG vectors, aggregates scores, and automatically declares a winner.

---

## 2. Technical Architecture & Routing

### A. Parallel Querying
When a benchmark request is received, the backend invokes model generation endpoints in parallel using multi-threaded execution or asynchronous tasks:
- **Local Models**: Communicates with Ollama's `/api/generate` locally.
- **Cloud Models**: Calls Google Gemini, Groq, DeepSeek, or OpenRouter REST endpoints depending on configured API keys in `.env`.

### B. Evaluation Metrics
For each responding model, the backend calculates:
1. **Latency**: Round-trip response time from query inception to completion.
2. **Groundedness**: Overlap and semantic coverage between the LLM's answer and the retrieved RAG vector context.
3. **Word Density**: The length and token count of the answer.
4. **Composite Score**: An aggregated quality rank score (out of 100).

---

## 3. API Contract (`POST /compare`)

The compare route runs parallel model tests and calculates ranks:
```json
{
  "results": [
    {
      "model": "qwen3:latest",
      "answer": "The core theme of the document focuses on...",
      "latency": 1.3,
      "grounded": 0.94,
      "words": 42,
      "score": 94
    },
    {
      "model": "phi:latest",
      "answer": "This document outlines...",
      "latency": 0.9,
      "grounded": 0.88,
      "words": 31,
      "score": 88
    }
  ],
  "winner": "qwen3:latest"
}
```

---

## 4. Database Log Serialization

Results generated by comparisons are synced to the MongoDB `analytics` collection.
```javascript
{
  "model": "qwen3:latest",
  "answer": "The core theme of the document focuses on...",
  "latency": 1.3,
  "words": 42,
  "length": 220,
  "grounded": 0.94,
  "retrieval": 1.0,
  "embed_model": "nomic-embed-text",
  "score": 94.0,
  "timestamp": ISODate("2026-06-20T12:00:00Z")
}
```
This is also exported into a CSV stylesheet file (`analytics.csv`) and printed as a PDF report.

---

## 5. UI Presentation (`Leaderboard.jsx` & `ModelTable.jsx`)

The comparison dashboard presents the results in three beautiful sections:
1. **🏆 Winner Announcement Banner**: A glowing emerald gradient block displaying the highest-rated model name, its composite score, and latency.
2. **🤖 AI Model Battle Matrix Table**: An explicit comparison table structured with five columns:
   - **Rank**: Ranging from `#1` to `#N` (sorted by score descending, then by latency ascending).
   - **Model**: Model tag name.
   - **Latency**: Output generation delay (seconds).
   - **Score**: Composite performance rating.
   - **Status**: Visual badge tags demarcating the "Winner" from "Contender" models.
3. **Accuracy & Speed Graphs**: Visual representations rendering latency curves, groundedness charts, and word distributions.
